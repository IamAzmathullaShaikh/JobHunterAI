# Glossary

- **ATS (Applicant Tracking System)**: Software used by employers to collect, sort, scan, and rank job applications.
- **Candidate Profile**: A structured JSON representation of a candidate's professional background.
- **JD (Job Description)**: The text provided by an employer describing a role.
- **Match Score**: A numerical value (0-100) indicating the fit between a profile and a JD.
- **PII (Personally Identifiable Information)**: Data that can be used to identify an individual (Name, Email, etc.).
- **Smart Router**: The JobHunterAI component that selects the best AI model for a given task.
- **STAR Method**: Situation, Task, Action, Result. A structured way of answering behavioral interview questions.
- **Tailoring**: The process of adjusting a resume to highlight specific skills required for a job.
